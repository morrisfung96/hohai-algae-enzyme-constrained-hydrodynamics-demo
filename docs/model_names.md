# Model names in the article and figures

| Original archive identifier | Public label | Scientific role |
| --- | --- | --- |
| R18 | Metabolic capacity | Environment-dependent metabolic growth capacity with the adopted ecological structure |
| R18E | Empirical capacity | Empirical growth-capacity comparator using the same ecological structure and evaluation basis |

The full prose names are **Metabolic-capacity model** and
**Empirical-capacity comparator**. Chinese manuscript labels are 代谢容量方案
and 经验容量对照方案.

The water-column/surface observation setting is identified separately. The
fixed x1.45 expression used for the capacity comparison and the depth-retention
surface-expression check retain their original sample and observation identities.
Changing a label does not change either setting or any prediction.

Original column names, configuration keys, script names, and source hashes are
retained for traceability. The model dictionary maps them to scientific labels.
The v0.1.1 update changes only reader-facing documentation, Figure 3 text, and
associated checksums. The numerical implementation and archived results remain
identical to v0.1.0.
